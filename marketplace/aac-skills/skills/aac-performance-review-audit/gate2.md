# Gate 2: Meaning (reading, yes or no per item)

Only after Gate 1 passes. Run every meaning check in `standards.md` (`../aac-review-self-check/standards.md`) against each item in turn: one Strength or Weakness, every check in order, then the next item; then the Core Message and Guidance checks.

Fix line form: "S3: sentence 2 is a list of five accounts; it must be one event or figure." "Core Message: the three areas named are W1 and W2; the Ramification must name the work of mine he takes on." No rewrites. The Bob examples carry the standard.

Work through every item, not only the ones that look wrong. Account for each Strength, each Weakness, the Core Message, and each Guidance point: it passes, or it carries a fix line. A sweep that stops at the first few problems costs a second Gate 2 round over items that were already in front of you.

Gate 2 email (passes the release gate in SKILL.md before it goes out): same skeleton, "However, there are [N] meaning fixes needed before I review the content for consistency:", then the standards: 1 SEER (with Bob), 2 Sum-Ex (with Bob), 3 pattern not one-off, 4 one example per item, 5 repeat items say so, 6 Ramification and the four Result definitions, 7 every Weakness has a Guidance point. Drop what passed. Add a voice standard if a fix line needs one.
