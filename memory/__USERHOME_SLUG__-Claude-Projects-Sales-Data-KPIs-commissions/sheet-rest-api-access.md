**Running Apps Script functions (`clasp run-function`) — WORKS, confirmed 2026-07-09.** `clasp run-function <fnName>` runs HEAD (devMode) with the standard clasp token — returned `pong` from `capabilityPing`. **Headless dispatch web app — the lever for private/underscore/new functions (confirmed 2026-07-20).** `doPost` in Core.js executes-as-owner over HTTPS, gated by `WEBAPP_SECRET` + a `DISPATCH` whitelist. To run something not in the whitelist (or a brand-new fn): add it to `DISPATCH`, `clasp push`, then `clasp deploy --description "..."` (a NEW versioned deployment — the plain `@HEAD` deployment has NO usable `/exec` URL, returns "Page Not Found"), then POST to `https://script.google.com/macros/s/<newDeploymentId>/exec`. **Use PowerShell `Invoke-RestMethod`, not curl** — curl mangles the body across Apps Script's 302 redirect (HTTP 411). Body: `{"secret":"…","functionName":"…","arguments":[…]}`. Whitelisted fns can be underscore-private (dispatch calls them directly, not via scripts.run). Clean up test deployments afterward with `clasp undeploy <id>`.
