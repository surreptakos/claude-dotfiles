Yes/no question gets one line: answer, what was done, when it gets fixed. Example Dan gave
(2026-09-02): "Yes, I stopped it and it will be fixed after this fleet run finishes."

**Why:** Dan asked "are you launching powershell windows"; reply ran 160 words of process
tables, commit hashes, fleet status. He wanted one sentence.

**How to apply:** Detail stays in tool results. Offer it only if asked. Related:
