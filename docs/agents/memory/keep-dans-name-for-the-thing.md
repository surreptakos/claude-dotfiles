Dan asked for an "authority registry". The reply proposed a repo named `aac-handbook`, a term
lifted from a chat transcript's recommended setup, and he stopped to ask whether the registry had
been renamed (2026-10-01).

**Why:** a new name for the thing he named reads as a different thing. He cannot tell whether the
plan changed or only the word, so the turn goes to asking. The stand-in was the transcript's
vocabulary; the primary source for the name was his own message.

**How to apply:** use his word for the deliverable in every reply, file name and repo name. When a
container needs a name of its own (a repo holding the registry plus policies), say in one line that
the registry is the page and the container is separate, and offer the name as his choice. See
[[state-a-standing-rule-once]].
