# Gate 2: Meaning (reading, yes or no per item)

Gate 2 is the `meaning` run SKILL.md's "Before anything" already made. Its fix lines go into the email verbatim, Jev's still tagged "(Jev)" so Dan sees which are judgments.

Reader judgment covers only what the run hands to a reader: each item on its Read list, and the reader checks it names (a repeat from the prior review, framing past the record), run by `standards.md` (`../aac-review-self-check/standards.md`) against each item in turn. A Read item that fails gets a fix line in the same form. Its comma counts are a note under the Notes line, never a fix.

Fix line form: "S3: sentence 2 is a list of five accounts; it must be one event or figure." "Core Message: the three areas named are W1 and W2; the Ramification must name the work of mine he takes on." No rewrites. The Bob examples carry the standard.

Done when every Strength, every Weakness, the Core Message and every Guidance point is accounted for: it passes, or it carries a fix line. A sweep that stops at the first few problems costs a second Gate 2 round over items that were already in front of you.

Gate 2 email (passes the release gate in SKILL.md before it goes out): the Gate 1 skeleton, "However, there are [N] meaning fixes needed before I review the content for consistency:", then the standards: 1 SEER (with Bob), 2 Sum-Ex (with Bob), 3 pattern not one-off, 4 one example per item, 5 repeat items say so, 6 Ramification and the four Result definitions, 7 every Weakness has a Guidance point. Drop what passed. Add a voice standard if a fix line needs one.

A new meaning question starts from the `typesafe:typesafe-ai` skill and gets a row in the table in `review_meaning.py`.
